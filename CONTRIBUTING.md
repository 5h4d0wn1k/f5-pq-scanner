# Contributing

Thank you for your interest in improving this project.

## Guidelines

- **Authorized use only.** This software is provided for defensive security education and authorized testing against systems you own or have explicit written permission to test.
- Open an issue before submitting large changes.
- Keep pull requests focused: one feature or fix per PR.
- Include or update tests when modifying logic.
- Run `python3 -m py_compile` and `python3 -m unittest discover` before submitting.
- Do not commit secrets, credentials, or personal information.

## Code Style

- Standard library preferred; justify any third-party dependency.
- Follow existing patterns in the codebase.
- Descriptive commit messages.

## Reporting Vulnerabilities

Do **not** open a public issue for security vulnerabilities. Instead, contact the maintainer through GitHub Security Advisories.
